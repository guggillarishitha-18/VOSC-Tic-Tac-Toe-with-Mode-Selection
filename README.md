# VOSC Activity-1 — Tic-Tac-Toe

## Interface

The game starts with a mode-selection screen:

- 🤖 Play with Robot
- 👥 Play with Friends

After selecting a mode, the Tic-Tac-Toe board opens.

## Files

- index.html
- style.css
- script.js
- README.md

## Features

- Mode selection interface
- Two-player mode
- Robot mode
- Winner detection
- Draw detection
- Score tracking
- Winning-cell highlighting
- New Game button
- Back button
- Responsive design
